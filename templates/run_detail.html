How scores work explains the problem scores and failure classifications. Test counts are the passed/collected tests captured during that evaluation itself; "not recorded" means the run predates evidence capture, or nothing was measured (a provider failure, or a plan score). Gate-failed testing rows show kills as "not measured", never zero. The Tests column opens the per-test detail for that row — which tests passed and failed as captured during that evaluation; rows without captured identities explain why instead of inventing names. The Evidence column is separate: it links to a failure-artifact file for that problem and provider, matched by nearest artifact filename timestamp (artifact files do not contain a run ID, so this association is heuristic, within 24 hours, not a guaranteed run foreign key). Older runs without artifacts simply show —.
